# Audio

Empty on purpose, and tracked so a clone keeps the directory (Phase 0 asserts it
exists; git does not store empty directories).

**Placeholders are not here.** The synthesised placeholder set lives in
`assets/audio/{sfx,music}/` and is generated by `tools/make_placeholder_audio.py`.
It sits under `assets/` so it travels in the asset bundle and stays out of git
history along with the art — see `docs/ASSET_DELIVERY.md`.

**This directory is for finished audio**: licensed music, recorded or commissioned
SFX, voice. Those are worth committing properly through Git LFS
(`.gitattributes` already routes audio there), which is why they get a home
outside the gitignored `assets/` tree.

To replace a placeholder, keep the slot name. `docs/generated/audio_slots.json`
maps every slot to its file, and `AudioDirector` only ever refers to slots — so a
finished file dropped over the same name changes nothing in the game code. The
guide's required families are listed in §14 of the master guide.
