# Usage and Production Notes

- The package is intended for the private Project Zero Climb prototype and
  first internal playtest.
- The included AI-generated images are prototype assets and creative
  references. They require human cleanup and consistency review before a
  commercial release.
- Do not copy protected characters, names, interfaces, music, sound effects,
  or art from other games. Creature-collection, summoning, auto-attacking, and
  roguelite inspirations must remain structural.
- No licensed audio, voice acting, fonts, or third-party asset packs are
  included.
- DejaVu Sans is used only while generating the guide and route-map files in
  this workspace; the game should use a properly licensed runtime font chosen
  during implementation.
- Preserve the original source filenames in the attached package so the
  manifest, guide, and Claude build brief remain valid.
